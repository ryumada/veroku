Installing Veroku

Veroku is a Progressive Web App (PWA) that installs locally without an app store, preserving full offline capability and adding an icon to your application menu or home screen.

💻 Chrome / Edge / Desktop

  1. Look for the Install icon in your browser address bar (or click Install App in the sidebar).
  2. Click Install when prompted. The app appears in your Start Menu / Applications list.

🤖 Android (Chrome / Firefox)

  1. Tap Install App in the menu, or open the browser menu (⋮) in the top-right.
  2. Select Install app or Add to Home screen.

🍏 iOS Safari (iPhone / iPad)

  1. Tap the Share button (box with upward arrow ⎋) in Safari.
  2. Scroll down and tap Add to Home Screen (➕).
  3. Tap Add in the top-right corner.
